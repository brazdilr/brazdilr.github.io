## 🎵 Správa skladeb v přehrávači

### Struktura kódu pro skladby:
Všechny skladby jsou definovány v `script.js` v `MusicPlayer` třídě (řádky 408-429):

```javascript
this.tracks = {
    pop: [
        { title: 'Popová píseň #1', file: 'https://...', duration: 30 },
        { title: 'Popová píseň #2', file: 'https://...', duration: 30 },
        // ... další skladby
    ],
    akusticka: [
        { title: 'Akustická píseň #1', file: 'https://...', duration: 28 },
        // ... další skladby
    ],
    detska: [
        { title: 'Dětská píseň #1', file: 'https://...', duration: 20 },
        // ... další skladby
    ],
    svatebni: [
        { title: 'Svatební píseň #1', file: 'https://...', duration: 26 },
        // ... další skladby
    ]
};
```

### Jak přidat novou skladbu:

#### **1. Přidat do existující kategorie:**
```javascript
pop: [
    { title: 'Popová píseň #1', file: 'https://...', duration: 30 },
    { title: 'Popová píseň #2', file: 'https://...', duration: 30 },
    { title: 'NOVÁ POPOVÁ PÍSEŇ', file: 'https://novy-url.mp3', duration: 35 }, // ← Přidat sem
],
```

#### **2. Přidat novou kategorii:**
```javascript
this.tracks = {
    pop: [...],
    akusticka: [...],
    detska: [...],
    svatebni: [...],
    nova_kategorie: [  // ← Přidat novou kategorii
        { title: 'Nová píseň #1', file: 'https://...', duration: 30 },
        { title: 'Nová píseň #2', file: 'https://...', duration: 25 },
    ]
};
```

#### **3. Přidat novou záložku v HTML:**
V `index.html` a `jak-to-funguje.html` přidat:
```html
<button class="category-tab" data-category="nova_kategorie">Nová kategorie</button>
```

### Struktura každé skladby:
- **`title`** - název písničky (zobrazí se v seznamu)
- **`file`** - URL k audio souboru (Supabase, YouTube, atd.)
- **`duration`** - délka v sekundách (volitelné, pro zobrazení)

### Praktický příklad - přidání nové skladby:

```javascript
// V kategorii "pop" přidat:
{ title: 'Moje nová píseň', file: 'https://yfoqiowdqqusnvbkyqhk.supabase.co/storage/v1/object/public/Ukazky-pisni/moje-nova-pisen.mp3', duration: 32 }
```

### Výhody této struktury:

#### **✅ Velmi přehledné**
- **Všechny skladby na jednom místě** (řádky 408-429)
- **Jasná struktura** - kategorie → skladby → vlastnosti
- **Snadné kopírování** - stačí zkopírovat řádek a upravit

#### **✅ Snadné úpravy**
- **Přidání skladby** - přidat řádek do kategorie
- **Změna názvu** - upravit `title`
- **Změna URL** - upravit `file`
- **Přidání kategorie** - přidat nový objekt do `tracks`

#### **✅ Žádné složité kódy**
- **Žádné databáze** - vše v jednom souboru
- **Žádné API volání** - statická data
- **Žádné složité logiky** - jednoduchá struktura

### Návod pro úpravy:

1. **Otevřít `script.js`**
2. **Najít sekci `this.tracks = {`** (řádek 408)
3. **Přidat/upravit skladby** v příslušné kategorii
4. **Uložit soubor** - změny se projeví okamžitě

**Žádné složité programování není potřeba** - stačí základní znalost JavaScript objektů a můžete snadno spravovat celý hudební katalog.
